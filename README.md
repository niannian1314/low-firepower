# low-firepower
Combat charm addon for TACZ (Timeless and Classics Zero) built on Curios: a 6-slot "firepower" curio slot with 9 equippable combat charms (bloodline, perspective, indifference, chain, rage, temperance, swift, dream, apocalypse) plus a craftable firepower core. MC 1.20.1, Forge 47.4+.
